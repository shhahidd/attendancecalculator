# Attendance Calculator

A simple web based Attendance Calculator built to help students calculate and track their attendance accurately.

This application calculates attendance using the **actual number of classes held and classes attended**, then determines whether attendance requirements are satisfied.

### Project Description

Attendance Calculator is designed to remove manual calculations and provide instant results using real attendance data. Users enter the total number of classes held, classes attended, and the required attendance percentage. Based on these values, the application performs calculations and displays attendance status.

The calculator can determine:

- Current attendance percentage
- Exact number of classes that can still be skipped while maintaining required attendance
- Exact number of additional classes that must be attended to reach the required attendance percentage
- Attendance status based on the selected criteria

### Technologies Used

- HTML
- CSS
- JavaScript

### Features

- Calculates attendance from actual class data
- Displays current attendance percentage
- Shows how many classes can be missed safely
- Shows how many consecutive classes are needed to recover attendance shortage
- Fast calculations with instant results
- Clean and responsive user interface

### How It Works

1. Enter required attendance percentage
2. Enter total classes held
3. Enter total classes attended
4. The calculator processes the values and shows exact attendance details

### Formula Used

Current Attendance:

Attendance % = (Classes Attended / Total Classes Held) × 100

Skip allowance and recovery classes are calculated dynamically based on the required attendance percentage.
